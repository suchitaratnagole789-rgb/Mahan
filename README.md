# Team Urban Warrior website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `team-urban-warrior` folder.
3. Open `index.html` in a modern browser.

For a local development server, use VS Code's Live Server extension or run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Customize before publishing
- Replace the placeholder team details in the About section.
- Add your actual project photos and approved logo.
- Verify all facts and add citations beside numerical claims.
- Confirm the solar estimate assumptions for your location and use case.
- Add a real contact form only after choosing a form backend or service.
- Test on mobile, keyboard navigation and multiple browsers.

## Files
- `index.html` — page structure and content
- `css/style.css` — responsive visual design
- `js/script.js` — mobile navigation and calculator

This is a front-end starter. It does not include a database, login system, form submission backend or hosting configuration.
